# 큐레이션·매칭 모델 — 양면 페르소나 + "내가 찾던 예술"

> Hidden Factory의 **목적**: 소비자와 작가를 연결한다. 웨딩앱(Dewy)이 페르소나로 초개인화 큐레이션을 하듯, 작가는
> 작품에만 집중하고 소비자는 **"내가 찾던 예술"** 을 발견하게 한다. 이 문서는 그 연결의 **양면 페르소나 + 공유 매칭
> 속성 + 큐레이션 모델 + 고령 장인 진입장벽 제로 설계**를 정의한다.
> 상위: [`marketing-plan.md`](./marketing-plan.md) · 엔진: [`copywriting-engine.md`](./copywriting-engine.md) · 모델: [`ai-model-strategy.md`](./ai-model-strategy.md).

---

## 0. 왜 양면인가 — 한쪽만 보면 연결이 안 된다

연결(matching)은 **공급(작가)** 과 **수요(소비자)** 가 **같은 언어(공유 속성)** 로 기술될 때만 가능하다. 따라서 페르소나도
양면으로 모델링하고, 둘을 잇는 **단일 매칭 속성 택소노미**(§3)를 둔다. (Dewy의 `weddingPersona.ts` → 미션/업체 매칭 구조 차용.)

**핵심 통찰**: 작가 마케팅 카피를 쓰려고 작품 사진을 분석한 **시각 브리프**([`copywriting-engine.md`](./copywriting-engine.md) §2.1)가
**그대로 매칭 인덱스**가 된다. 즉 한 엔진이 ① 작가 마케팅 ② 소비자 큐레이션을 동시에 만든다.

### 0.1 우선순위 — 소비자가 북극성 (확정)

양면이지만 **설계·구현의 1순위는 소비자**다. "소비자를 기준으로 **최대한 개인화**하고, **가치를 느끼고 충족**하게"가
제품의 중심(§2·§4·§4.5). **작가 측은 그 경험에 공급을 대는 enabler**로, **플로우를 최소화**한다(§5 — 사진만, 또는
우리가 대신 등록). 따라서 이 문서는 작가 페르소나(§1)를 먼저 정의하지만, **무게는 소비자(§2 이하)에 둔다.**
콜드스타트(공급 부족)는 "작가 플로우 최소화 = 우리가 대신 채움(컨시어지)"으로 푼다(§5·§6).

## 1. 작가(공급) 페르소나 — A1~A4

| # | 페르소나 | 상황 | 핵심 needs | 마찰 | 1순위 기능 |
|---|---|---|---|---|---|
| **A1 ★** | **고령 장인 (디지털 약자)** | 손맛·실력 최고, 스마트폰·마케팅·온라인 판로 막막. (소상공인 54.8%가 50대+) | **초저마찰**: 사진만 올리면 AI가 전부 | 앱 사용·글쓰기·채널 운영 전부 부담 | 저마찰 온보딩(§5) · 마케팅 대행 |
| A2 | **전업 작가 (판로 확장형)** | idus/스마트스토어 운영하나 고수수료·노출 게이팅·디자인 도용에 지침 | 채널 확장 + 작가 중심 스토리텔링 | 플랫폼 종속·수익 압박 | 멀티채널 콘텐츠 · 작가 서사 |
| A3 | **투잡/신진 작가** | 본업 있고 시간 없음, 막 시작 | 자동화·속도 | 뭘·어떻게 올릴지 막막 | 빠른 콘텐츠 생성 |
| A4 | **클래스/체험 중심 작가** | 원데이/정규 클래스가 주수입 | 모집·단골 관리 | 모집글·리마인드 반복 노동 | 단골 메시지 · 모집 콘텐츠 |

> **A1이 1순위 웨지.** idus 등 기존 플랫폼이 "상품 중심·셀러 운영 복잡"이라 못 품는 층. 이들을 AI 대행으로 해방하는 것이 차별의 핵심.

## 2. 소비자(수요) 취향 페르소나 — C1~C5

"내가 찾던 예술"의 주인공. 각 페르소나는 **서로 다른 매칭축**을 1순위로 쓴다.

| # | 페르소나 | 발견 동기 | 1순위 매칭축 | 큐레이션 진입점 |
|---|---|---|---|---|
| C1 | **선물 탐색형** | 의미 있는 선물(집들이·기념일·감사) | 계기 · 예산 · 받는사람 | "OO에게 줄 선물" 플로우 |
| C2 | **나를 위한 소비/수집형** | 내 취향·공간을 채울 작품 | 스타일 · 무드 | 취향 입력 → 추천 피드 |
| C3 | **인테리어/공간 스타일링형** | 집·카페·오피스 꾸미기 | 색감 · 사이즈 · 공간 | 공간/컬러 기반 탐색 |
| C4 | **경험·클래스 추구형** | 사기보다 만드는 경험 | 지역 · 난이도 · 관심분야 | 지역·카테고리 클래스 탐색 |
| C5 | **맞춤 의뢰형** | 세상에 없는 커스텀 | 의뢰가능 작가 · 예산 · 납기 | 의뢰 매칭 플로우 |

> **가치지향**(수제·로컬·친환경·작가 직접 지원)은 모든 C에 걸치는 **cross-cutting 태그** — "지원소비" 동기를 강화하는 필터.

## 3. 공유 매칭 속성 택소노미 (브리지) — 단일 소스

작품(작가)과 취향(소비자) **양쪽을 동일 속성으로 태깅**해 매칭한다. 아래가 **유일한 속성 정의**(문서 간 드리프트 금지).

| 속성 | 값 예시 | 작품 측 출처 | 소비자 측 출처 |
|---|---|---|---|
| `category` | 도자기·레진·회화·캘리·유리·한지·기타 | 작가 입력/시각브리프 | 관심 카테고리 |
| `style` | 미니멀·내추럴·빈티지·모던·클래식·키치 | 시각 브리프 | 취향 온보딩 |
| `mood` | 따뜻·차분·화사·시크·러스틱 | 시각 브리프 | 취향 온보딩 |
| `color` | 색 팔레트(톤) | 시각 브리프 | 공간/취향 입력 |
| `price_tier` | 1~5만 / 5~15만 / 15만+ | 작가 입력 | 예산 |
| `occasion` | 선물·집들이·자기소장·인테리어·클래스 | 카피/용도 | 발견 동기 |
| `region` | 시도/시군구 | 공방 위치(`korea-regions.ts`) | 거주/희망 지역 |
| `values` | 수제·로컬·친환경·소량 | 작가 입력 | 가치 필터 |

> 작품 측 `style·mood·color·occasion`은 **시각 브리프에서 자동 추출**(copywriting-engine §2.1) → 작가 추가 입력 최소화(A1 친화).

## 4. 매칭/큐레이션 모델 — "내가 찾던 예술" 피드

```
[작가] 작품 사진 → 시각 브리프(자동 태깅) ──┐
                                             ├─→ 공유 속성 인덱스 ─→ 유사도 매칭 ─→ 개인화 발견 피드
[소비자] 취향 온보딩 + 행동 학습 → 취향 프로파일 ┘
```

- **소비자 취향 프로파일**: ① **콜드스타트** — 온보딩에서 소수 입력(좋아하는 무드·스타일 이미지 몇 장 택1, 용도, 예산).
  ② **행동 학습** — 클릭·저장·구매·체류로 프로파일 보정(웨딩앱이 입력으로 페르소나 분기하듯).
- **매칭**: 규칙 기반(속성 일치 가중) + **임베딩 유사도**(취향·작품 벡터 — [`ai-model-strategy.md`](./ai-model-strategy.md) §6) 하이브리드.
- **큐레이션 피드**: "발견 모드"를 만드는 정제된 피드(상품 더미 나열 금지 — idus 차별). 작가 **스토리텔링**을 전면에
  (작가-소비자 감정 연결이 전환을 높임). 다양성·신진작가 노출 보정(필터버블·과포화 방지).
- **설명 가능성**: "이 작품을 추천한 이유"(취향 무드/색감 일치)를 노출 → "내가 찾던 예술"의 납득감.

## 4.5 소비자 가치·개인화 모델 (★제품의 북극성)

소비자 유입이 1순위인 만큼, **"최대한 개인화 → 가치를 느끼고 → 그 가치를 실제로 충족"** 의 3단계를 끝까지 설계한다.

### (1) 최대한 개인화 — *느끼게 하는* 정확도
- **점진적 취향 학습**: 콜드스타트(이미지 택1 취향 퀴즈·용도·예산) → 행동(클릭·저장·구매·체류)으로 프로파일 **계속 보정**.
  웨딩앱이 입력으로 페르소나를 분기하듯, 소수 입력만으로도 첫 추천이 "어떻게 알았지?" 수준이 되게.
- **맥락 인지**: 같은 사람도 "선물(C1)"일 땐 다른 축으로 — 계기·받는사람·공간을 물어 **상황별 큐레이션**.
- **다양성·세렌디피티**: 똑같은 것만 보여주지 않기(필터버블 방지). "취향 근처의 새로운 발견" 슬롯을 의도적으로 섞어 신진 작가 노출도 함께.

### (2) 가치를 *느끼게* — 발견의 정서
- **"내가 찾던 예술" 모먼트**: 추천 이유(무드·색감·계기 일치)를 짧게 노출 → 납득과 감탄.
- **작가 서사 전면 (인터뷰 영상)**: 작가 소개 페이지의 **편집된 인터뷰 영상**(얼굴·목소리·손맛)으로 작품에 **사람**을
  붙인다(§5.2). 손맛·제작 과정·의도를 작가의 실제 말로 — 상품 나열(idus)이 못 주는 감정 연결.
- **지원소비 가치**: "이 작품을 사면 OO 장인을 직접 응원" — 로컬·수제·지원의 의미를 부여(가치지향 페르소나 강화).

### (3) 가치를 *충족* — 실제 만족까지
- **신뢰·진본성**: 수제·소량·작가 검증 표식, 디자인 도용 모니터링(idus 미흡점 보완).
- **불안 선제 해소**: 배송·교환·맞춤 납기 등 구매 직전 불안을 큐레이션 카드/카피에서 미리 해소.
- **사후 만족 루프**: 구매 후 후기·재추천("이 작가의 다음 작품", "비슷한 결의 다른 작가")으로 만족을 다음 발견으로 환류.
- **성취 측정**: 매칭 만족도("내가 찾던 예술이었나"), 발견→저장→구매 전환, 재방문 — 개인화 품질의 직접 KPI.

> 이 3단계가 소비자 KPI([`marketing-plan.md`](./marketing-plan.md) §9)와 1:1 대응한다. 작가 측 산출(시각 브리프·서사·신뢰표식)은
> 모두 이 소비자 가치를 채우기 위한 재료다.

## 5. 작가 플로우 최소화 = 공급 enabler (저마찰 온보딩, A1 1순위)

소비자 경험이 1순위라도 **공급(작품)** 이 있어야 큐레이션이 산다. 그래서 작가 측은 **"부담은 0에 가깝게, 공급은
빠르게"** 가 목표다. idus의 복잡한 셀러 운영(가격 정책·기획전 신청·멤버십·배송 설정)이 고령 장인을 밀어낸다 — 우리는 **정반대**.

### 5.1 작가(평균 50대)의 평생 업무 = 딱 3가지

작가가 하는 일은 **이 셋뿐**이고, 그 외 전부(설명·태그·스토리·카피·가격제안·발행·마케팅·큐레이션)는 **우리/AI가 대행**한다.
목표는 **작가가 오롯이 작품활동에만 집중**하게 하는 것.

1. **초기 인터뷰**(1회) — 우리가 직접 찾아가 진행. 작가는 **말하기만**.
2. **작품 사진 촬영·업로드** — 신작이 나오면 사진만 찍어 올린다(작가의 유일한 반복 작업).
3. **마일스톤 추가 인터뷰** — 전시회·수상 등 프로필 갱신 거리가 생겼을 때만 짧게 추가 인터뷰.

### 5.2 인터뷰 = hero 영상 + 데이터 원천

- **영상**: 인터뷰를 편집해 **작가 소개 페이지에 첨부**(얼굴·목소리·손맛 = 바튼이 말한 "사람"). 큐레이션 발견 경험의 정서 핵심.
- **데이터 원천(소스 오브 트루스)**: 인터뷰 내용에서 **작가 스토리·`match_tags`·브랜드 보이스·작품 맥락**을 추출해 채운다.
  AI는 **무에서 지어내지 않고 인터뷰에 근거**해 카피를 쓴다 → **진짜 목소리 보존(동질화 방지)** + 환각 차단([`copywriting-engine.md`](./copywriting-engine.md) §1.1·§2).
- **사진 → AI가 나머지**: 업로드된 사진은 시각 브리프(=매칭 인덱스)로 자동 분석되고, 인터뷰 보이스와 합쳐져 설명·태그·가격제안·발행 초안이 자동 생성된다.
- **프로필 자동 유지**: 전시·수상 등은 마일스톤 인터뷰로만 받아 **우리가 입력·갱신**. 작가는 폼을 채우지 않는다.

### 5.3 접근성·신뢰

- **UI 접근성**(사진 업로드 단계): 큰 글씨·고대비·단계 최소·전문용어 제거(모바일 웹 가정). 막히면 **전화/카톡 지원·대리 업로드**.
- **신뢰·보호**: 작가 중심(작가 노출·서사·인터뷰 영상) + 디자인 도용 모니터링(idus 미흡점 보완)으로 입점 신뢰 확보.

> 검증: A1(고령 장인) walkthrough로 **"인터뷰 1회 + 사진 업로드만으로 작품활동에 지장 없이 운영되는가"** 확인(폼 강요·막다른 단계 0).

  적재(매칭 인덱스). **작가 프로필(인터뷰 영상 URL + 인터뷰 추출 스토리·보이스)** 저장 필드 + 소비자 취향/매칭 테이블 신설
  (이번 문서 범위 밖, 후속 스키마 작업 — 기존 `stores`/`artworks` 확장 또는 별도 테이블).
- **Phase 2 (개인화 심화 + 가치)**: 행동 학습·설명가능 추천·**임베딩(pgvector)**·가치 메시지(§4.5). 매칭 정확도·만족도 KPI 개선.
- **Phase 3 (작가 셀프서비스 확장)**: 작가 대면 마케팅 도구 UI 전면 개방으로 **공급 스케일**(작가 플로우 최소 유지). 작품
  측 `values·price_tier` 입력·`artworks` 태그 표준화.
- **콜드스타트 해법**: 작가 인덱스 부족은 **우리가 대신 채움(컨시어지, §5)** 으로 풀어 소비자 경험을 day-1부터 풍부하게.
