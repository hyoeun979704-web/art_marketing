# 큐레이션·매칭 모델 — 양면 페르소나 + "내가 찾던 예술"

> Hidden Factory의 **목적**: 소비자와 작가를 연결한다. 웨딩앱(Dewy)이 페르소나로 초개인화 큐레이션을 하듯, 작가는
> 작품에만 집중하고 소비자는 **"내가 찾던 예술"** 을 발견하게 한다. 이 문서는 그 연결의 **양면 페르소나 + 공유 매칭
> 속성 + 큐레이션 모델 + 고령 장인 진입장벽 제로 설계**를 정의한다.
> 상위: [`marketing-plan.md`](./marketing-plan.md) · 엔진: [`copywriting-engine.md`](./copywriting-engine.md) · 모델: [`ai-model-strategy.md`](./ai-model-strategy.md).

---

## 0. 왜 양면인가 — 한쪽만 보면 연결이 안 된다

연결(matching)은 **공급(작가)** 과 **수요(소비자)** 가 **같은 언어(공유 속성)** 로 기술될 때만 가능하다. 따라서 페르소나도
양면으로 모델링하고, 둘을 잇는 **단일 매칭 속성 택소노미**(§3)를 둔다. (Dewy의 `weddingPersona.ts` → 미션/업체 매칭 구조 차용.)

**핵심 통찰**: 작가 마케팅 카피를 쓰려고 작품 사진을 분석한 **시각 브리프**([`copywriting-engine.md`](./copywriting-engine.md) §2.1)가
**그대로 매칭 인덱스**가 된다. 즉 한 엔진이 ① 작가 마케팅 ② 소비자 큐레이션을 동시에 만든다.

---

## 1. 작가(공급) 페르소나 — A1~A4

| # | 페르소나 | 상황 | 핵심 needs | 마찰 | 1순위 기능 |
|---|---|---|---|---|---|
| **A1 ★** | **고령 장인 (디지털 약자)** | 손맛·실력 최고, 스마트폰·마케팅·온라인 판로 막막. (소상공인 54.8%가 50대+) | **초저마찰**: 사진만 올리면 AI가 전부 | 앱 사용·글쓰기·채널 운영 전부 부담 | 저마찰 온보딩(§5) · 마케팅 대행 |
| A2 | **전업 작가 (판로 확장형)** | idus/스마트스토어 운영하나 고수수료·노출 게이팅·디자인 도용에 지침 | 채널 확장 + 작가 중심 스토리텔링 | 플랫폼 종속·수익 압박 | 멀티채널 콘텐츠 · 작가 서사 |
| A3 | **투잡/신진 작가** | 본업 있고 시간 없음, 막 시작 | 자동화·속도 | 뭘·어떻게 올릴지 막막 | 빠른 콘텐츠 생성 |
| A4 | **클래스/체험 중심 작가** | 원데이/정규 클래스가 주수입 | 모집·단골 관리 | 모집글·리마인드 반복 노동 | 단골 메시지 · 모집 콘텐츠 |

> **A1이 1순위 웨지.** idus 등 기존 플랫폼이 "상품 중심·셀러 운영 복잡"이라 못 품는 층. 이들을 AI 대행으로 해방하는 것이 차별의 핵심.

## 2. 소비자(수요) 취향 페르소나 — C1~C5

"내가 찾던 예술"의 주인공. 각 페르소나는 **서로 다른 매칭축**을 1순위로 쓴다.

| # | 페르소나 | 발견 동기 | 1순위 매칭축 | 큐레이션 진입점 |
|---|---|---|---|---|
| C1 | **선물 탐색형** | 의미 있는 선물(집들이·기념일·감사) | 계기 · 예산 · 받는사람 | "OO에게 줄 선물" 플로우 |
| C2 | **나를 위한 소비/수집형** | 내 취향·공간을 채울 작품 | 스타일 · 무드 | 취향 입력 → 추천 피드 |
| C3 | **인테리어/공간 스타일링형** | 집·카페·오피스 꾸미기 | 색감 · 사이즈 · 공간 | 공간/컬러 기반 탐색 |
| C4 | **경험·클래스 추구형** | 사기보다 만드는 경험 | 지역 · 난이도 · 관심분야 | 지역·카테고리 클래스 탐색 |
| C5 | **맞춤 의뢰형** | 세상에 없는 커스텀 | 의뢰가능 작가 · 예산 · 납기 | 의뢰 매칭 플로우 |

> **가치지향**(수제·로컬·친환경·작가 직접 지원)은 모든 C에 걸치는 **cross-cutting 태그** — "지원소비" 동기를 강화하는 필터.

## 3. 공유 매칭 속성 택소노미 (브리지) — 단일 소스

작품(작가)과 취향(소비자) **양쪽을 동일 속성으로 태깅**해 매칭한다. 아래가 **유일한 속성 정의**(문서 간 드리프트 금지).

| 속성 | 값 예시 | 작품 측 출처 | 소비자 측 출처 |
|---|---|---|---|
| `category` | 도자기·레진·회화·캘리·유리·한지·기타 | 작가 입력/시각브리프 | 관심 카테고리 |
| `style` | 미니멀·내추럴·빈티지·모던·클래식·키치 | 시각 브리프 | 취향 온보딩 |
| `mood` | 따뜻·차분·화사·시크·러스틱 | 시각 브리프 | 취향 온보딩 |
| `color` | 색 팔레트(톤) | 시각 브리프 | 공간/취향 입력 |
| `price_tier` | 1~5만 / 5~15만 / 15만+ | 작가 입력 | 예산 |
| `occasion` | 선물·집들이·자기소장·인테리어·클래스 | 카피/용도 | 발견 동기 |
| `region` | 시도/시군구 | 공방 위치(`korea-regions.ts`) | 거주/희망 지역 |
| `values` | 수제·로컬·친환경·소량 | 작가 입력 | 가치 필터 |

> 작품 측 `style·mood·color·occasion`은 **시각 브리프에서 자동 추출**(copywriting-engine §2.1) → 작가 추가 입력 최소화(A1 친화).

## 4. 매칭/큐레이션 모델 — "내가 찾던 예술" 피드

```
[작가] 작품 사진 → 시각 브리프(자동 태깅) ──┐
                                             ├─→ 공유 속성 인덱스 ─→ 유사도 매칭 ─→ 개인화 발견 피드
[소비자] 취향 온보딩 + 행동 학습 → 취향 프로파일 ┘
```

- **소비자 취향 프로파일**: ① **콜드스타트** — 온보딩에서 소수 입력(좋아하는 무드·스타일 이미지 몇 장 택1, 용도, 예산).
  ② **행동 학습** — 클릭·저장·구매·체류로 프로파일 보정(웨딩앱이 입력으로 페르소나 분기하듯).
- **매칭**: 규칙 기반(속성 일치 가중) + **임베딩 유사도**(취향·작품 벡터 — [`ai-model-strategy.md`](./ai-model-strategy.md) §6) 하이브리드.
- **큐레이션 피드**: "발견 모드"를 만드는 정제된 피드(상품 더미 나열 금지 — idus 차별). 작가 **스토리텔링**을 전면에
  (작가-소비자 감정 연결이 전환을 높임). 다양성·신진작가 노출 보정(필터버블·과포화 방지).
- **설명 가능성**: "이 작품을 추천한 이유"(취향 무드/색감 일치)를 노출 → "내가 찾던 예술"의 납득감.

---

## 5. 저마찰 장인 온보딩 (접근성 — A1을 위한 1순위 설계)

idus의 복잡한 셀러 운영(가격 정책·기획전 신청·멤버십·배송 설정)이 고령 장인을 밀어낸다. 우리는 **정반대**로 간다.

- **사진만 → AI가 전부**: 작품 사진 1장 업로드 → AI가 설명·태그·스토리·가격 제안·채널 발행 초안을 **대행**. 작가는 확인·수정만.
- **음성 입력**: 글쓰기 부담 제거 — 말로 "이건 3개월 말린 옻칠 그릇이에요" → AI가 카피·태그로 변환.
- **UI 접근성**: 큰 글씨·고대비·단계 최소·전문용어 제거. (모바일 웹 주 사용 가정.)
- **사람 안전망**: 막히면 전화/카톡 지원·대리 등록. 디지털 약자 배려.
- **신뢰·보호**: 작가 중심(작가 노출·서사) + 디자인 도용 모니터링(idus 미흡점 보완)으로 입점 신뢰 확보.

> 검증: A1 페르소나 walkthrough로 "사진 1장만으로 발행까지 끝까지 가는가"를 확인(placeholder/막다른 단계 금지).

## 6. 데이터 모델 & 단계적 전개

- **지금(Phase 2)**: 작가 도구로 시작. 시각 브리프 태깅을 `marketing_contents.meta`(매칭 속성)에 적재 → **매칭 인덱스 누적**.
  스키마 변경 없음(기존 테이블 재사용).
- **Phase 2b**: 작품별 매칭 속성 표준화 적재 + 작가 측 `values·price_tier` 입력. (필요 시 `artworks`에 태그 컬럼/별도 태그 테이블 — 후속.)
- **Phase 3(소비자 발견 면)**: 소비자 계정·**취향 프로파일 테이블**·**임베딩(pgvector)**·발견 피드 신설. 양면 RLS·노출
  공정성 설계. → 별도 기획·스키마 작업(이번 범위 밖).
- **진입 조건**: 작가·작품 인덱스가 일정 규모 누적되어야 소비자 큐레이션이 의미 있음(콜드스타트 공급 먼저).
