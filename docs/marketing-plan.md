# Hidden Factory 마케팅 기획서 — 공방 원장님을 위한 AI 마케팅 자동화

> 작성 전제(2026-06): 제품은 **작가(공방 원장님: 레진·도자기·회화·캘리그래피·유리·한지·기타)** 와 **소비자**를
> **연결**하는 SaaS. **작가는 작품에만 집중하고**, AI가 마케팅·판로·스토리텔링을 대신해 **소비자는 "내가 찾던 예술"을
> 초개인화 큐레이션으로 발견**한다. 현재 auth + 온보딩 + DB 스키마만 있고 **핵심 기능(AI 생성기·큐레이션)은 미구현**.
> 본 문서는 그 청사진이며, "마케팅의 신" 조 비테일(Joe Vitale)의 카피 관점으로 설계한다.
> 자매 문서: [`curation-matching.md`](./curation-matching.md)(양면 페르소나·매칭) · [`copywriting-engine.md`](./copywriting-engine.md)(엔진) · [`ai-model-strategy.md`](./ai-model-strategy.md)(모델).

## TL;DR

- **누가**: ① **작가** — 작품은 최고지만 마케팅·온라인 판로가 막막한 공방 원장님(특히 **고령 장인**). ② **소비자** — "내가 찾던 예술"을 찾는 사람.
- **무엇을**: 작가는 **사진만** 올리면 AI가 5종 마케팅 콘텐츠 + 매칭 태그를 자동 생성. 소비자는 **취향 기반 큐레이션 피드**로 작가·작품을 발견.
- **왜 우리 (vs 아이디어스)**: idus는 **상품 중심·고수수료·셀러 운영 복잡** → 작가가 안 보이고 고령 장인은 진입조차 어렵다. 우리는 ① **진입장벽 제로**(사진만, AI 대행) ② **작가 중심 스토리텔링** ③ **초개인화 큐레이션**.
- **한 문장 포지셔닝**: **"작가는 작품에만. 마케팅도, 판로도, 손님 연결도 Hidden Factory가."**
- **브랜딩(소비자 voice)**: **"내가 찾던 예술"** (대안 비교 §3.5).

## 0. 공통 토대 — 제품이 서기 위한 전제

이 제품은 **양면(two-sided)** 이다 — 작가(공급)와 소비자(수요)를 잇는다. 따라서 층위가 셋:

1. **작가 기능**(작가가 AI로 만드는 마케팅 콘텐츠 + 자동 매칭 태그) — §4~6 핵심.
2. **소비자 큐레이션**(소비자가 취향으로 작가·작품을 발견) — [`curation-matching.md`](./curation-matching.md), 단계적 전개.
3. **제품 마케팅**(우리가 작가·소비자를 모으는 활동) — §7 로드맵. "도그푸딩": 우리 엔진으로 우리 콘텐츠를 만든다.

**무게중심**: 지금은 1번(작가 기능)으로 시작하되 **2번의 매칭 속성을 처음부터 설계**해 연결로 확장한다.
연결의 다리 = 작가 콘텐츠 생성 시 나오는 **시각 브리프가 곧 소비자 매칭 인덱스**([`curation-matching.md`](./curation-matching.md) §0).

- **포지셔닝 한 문장**: "작가는 작품에만. 마케팅도, 판로도, 손님 연결도 Hidden Factory가."
- **3대 메시지 축**(모든 콘텐츠·기능은 이 중 하나에 귀속):
  1. **진입장벽 제로** — 고령 장인도 **사진만** 올리면 AI가 설명·태그·스토리·발행까지 대행([`curation-matching.md`](./curation-matching.md) §5).
  2. **작가 중심 스토리텔링** — 상품 스펙 나열(=idus)이 아니라, 손맛·서사로 작가와 소비자를 감정으로 연결.
  3. **초개인화 큐레이션** — 소비자가 취향으로 **"내가 찾던 예술"** 을 발견(작품 시각 브리프 = 매칭 인덱스).

## 1. 국내 공방 마케팅 시장 분석 (2025–26)

### 1.1 채널 지형 — "네이버 유입 × 인스타 × 스마트스토어 + AI/GEO"

- **3채널 통합이 기본값.** 고객이 어떤 경로로 검색하든 발견되도록 **네이버 유입 → 인스타 신뢰 → 스마트스토어 전환**을
  하나로 묶는 전략이 2026 소상공인 마케팅의 핵심.
- **네이버**: 블로그 체험단·인플루언서 포스팅은 자체 운영 대비 초기 노출 3~5배. **ADVoost(AI 쇼핑광고 자동화)** 로
  소재 없이도 예산만 넣으면 적합 사용자에게 노출. 스마트스토어 ↔ 크리에이터 제휴(쇼핑 커넥트).
- **인스타그램**: 릴스·**라이브커머스** 급성장. 공방은 "비하인드·제작 과정·완성 순간"이 강력한 시각 자산.
- **마이크로 인플루언서**: 대형 계정보다 진정성·신뢰도 높아 공방 타깃에 적합.
- **AI/GEO(Generative Engine Optimization)**: AI 검색엔진이 내 콘텐츠를 신뢰 출처로 인용하도록 최적화하는 흐름 부상.
  → 우리 생성 콘텐츠는 **사실 기반·구조화**(환각 배제)로 GEO 친화적이어야 한다.

### 1.2 경쟁사 분석 — 아이디어스(idus)의 빈틈

국내 핸드메이드 1위 idus가 가장 가깝다. 하지만 **상품 중심**이라 작가가 안 보이고, 고령 장인은 진입조차 어렵다.

| idus의 문제 | 내용 | 우리의 빈틈 공략 |
|---|---|---|
| **고수수료** | 판매 15~22%, 멤버십 5만원 + 무료배송비 작가 전가 → 저단가 작가 적자 | 작가 부담 최소·작가 중심 수익 구조 |
| **노출 게이팅** | 멤버십 안 하면 기획전·집중 노출 제한 | 취향 매칭 기반 공정 노출(신진·다양성 보정) |
| **상품 중심** | 작가 서사 안 보임, 상품 더미 나열 | **작가 스토리텔링 전면**(감정 연결 → 전환↑) |
| **셀러 운영 복잡** | 가격정책·기획전 신청·배송 설정 → 고령 장인 진입 불가 | **사진만 → AI 전부 대행**(진입장벽 제로) |
| **디자인 도용 방치** | 제재 미흡 → 작가 이탈 | 도용 모니터링·작가 보호 |

> 마켓플레이스 성공 공식(리서치): **스토리텔링 > 상품 나열**(전환↑), **큐레이션 피드 → "발견 모드" → CTR↑**, 맥락
> 사진 +45% 클릭. → 우리의 작가 중심 + 큐레이션 방향과 일치.
> 출처: [비즈한국 idus 수수료 논란](https://www.bizhankook.com/bk/article/27306) ·
> [한경 작가 불만](https://www.hankyung.com/article/202403087565g) · [나무위키 idus](https://namu.wiki/w/%EC%95%84%EC%9D%B4%EB%94%94%EC%96%B4%EC%8A%A4) ·
> [Etsy 대안 큐레이션(Shopify)](https://www.shopify.com/blog/etsy-alternatives).

### 1.3 핵심 페인포인트 — 고령 장인의 디지털 진입장벽 (= 우리의 1순위 웨지)

- **소상공인 54.8%가 50대 이상.** 고령층 30%는 앱 사용 미숙, 정보 생산·공유 참여는 38.9%뿐. 즉 **손맛은 최고지만
  마케팅·온라인 판로는 막막한 장인**이 다수. 정부도 온라인 판로 개척·디지털 역량 지원사업을 별도 운영할 만큼 인정된 문제.
- → **사진 한 장만으로 마케팅·판로·연결이 끝나는 경험**이 곧 차별이자 사회적 가치.

| 작가 페인포인트 | 현실 | 우리 해법 |
|---|---|---|
| **마케팅·판로 막막**(특히 고령) | 글쓰기·채널운영·플랫폼 입점 전부 부담 | **사진만 → AI 전부 대행**([`curation-matching.md`](./curation-matching.md) §5) |
| **작가가 안 보임** | 상품만 팔리고 작가 서사 소실 | 작가 중심 스토리텔링 카피 |
| **글쓰기·톤** | "사고 싶게" 못 씀, 채널마다 톤 제각각 | 조 비테일 benefit 엔진 + 채널 자동 최적화 |
| **법규 모름** | 단골 문자가 불법(미동의 광고)일 수 있음 | 정보통신망법 자동 준수 |
| **소비자와 연결 안 됨** | 좋은 작품이 맞는 손님을 못 만남 | 취향 매칭 큐레이션 |

> 출처: [KCA 고령 디지털 격차](https://www.kca.go.kr/home/board/download.do?menukey=6102&fno=10037209&bid=00000160&did=1003436954) ·
> [중장년 소상공인 온라인 마케팅 지원](https://www.someofficial.com/Additionalactivities/?bmode=view&idx=137539583) ·
> [원플랜마케팅 2026 가이드](https://oneplan.co.kr/small-business-marketing-guide-2026) · [오픈서베이 2025 소셜미디어](https://blog.opensurvey.co.kr/article/socialmedia-2025-2/).

## 2. 타깃 페르소나 (양면 — 요약)

연결(matching)을 하려면 **공급(작가)** 과 **수요(소비자)** 를 함께 모델링해야 한다. 상세·매칭축은 [`curation-matching.md`](./curation-matching.md).

- **작가(공급) A1~A4**: **A1 고령 장인(디지털 약자) ★1순위 웨지** · A2 전업(판로 확장) · A3 투잡/신진 · A4 클래스 중심.
- **소비자(수요) C1~C5**: C1 선물 탐색 · C2 나를 위한 소비/수집 · C3 인테리어/공간 · C4 경험·클래스 · C5 맞춤 의뢰.
- **잇는 다리**: 양쪽을 **공유 매칭 속성**(스타일·무드·색감·가격대·용도·지역·가치관)으로 태깅 → 큐레이션([`curation-matching.md`](./curation-matching.md) §3).

> 작가 측 속성은 작품 사진의 **시각 브리프에서 자동 추출**되어 A1(고령 장인)의 입력 부담을 없앤다.
> 카테고리는 기존 `lib/schemas/onboarding.ts`의 `CATEGORY_LABELS`(=`store_category` enum), 지역은 `lib/data/korea-regions.ts` 재사용.

## 3. 카피 철학 (조 비테일) & 브랜딩

### 3.1 조 비테일 카피 철학
핵심 명제 **"매 사실을 말할 때마다 그것이 고객에게 주는 이득을 함께 말하라"** 를 카피 엔진의 뼈대로 삼는다.
- **작가 가치를 언어로 (Hypnotic/Benefit)** — feature("유광 마감")를 즉시 benefit("물때가 안 껴 설거지가 편한")으로.
- **작가 서사 전면 (스토리텔링)** — 바넘 "받은 값 이상" = 손맛·제작 비하인드로 감정 연결(상품 나열=idus 차별).
- **채널마다 자동 최적화** — 같은 작품도 인스타(감성)·스토어(신뢰)·문자(따뜻)로. 상세: [`copywriting-engine.md`](./copywriting-engine.md).

### 3.2 브랜딩 — "내가 찾던 예술" + 대안 비교
브랜딩은 **소비자의 발견 순간**을 담아야 한다(연결이 목적). 기본안 + 대안을 비교한다. **목적은 불변** — 최종 선택은 사용자 몫.

| 후보 | voice | 강점 | 약점 | 양면 포괄 |
|---|---|---|---|---|
| **"내가 찾던 예술"** (기본) | 소비자 발견 | 큐레이션 핵심 약속 직격, 감정적 | 작가(공급) 측이 안 보임 | △(소비자 중심) |
| "작품은 작가가, 연결은 우리가" | 양면 선언 | 작가↔소비자 연결·작가 중심 명확 | 슬로건이 길고 기능적 | ◎ |
| "취향으로 잇다" | 매칭 | 짧고 매칭 본질, 확장성 | 다소 추상적 | ◎ |
| "오래 찾던 그 손끝" | 소비자+장인 | 장인의 손맛 + 발견 결합, 정서적 | 해석 여지 | ○ |

> **추천**: 소비자 대면 슬로건은 **"내가 찾던 예술"** 유지(발견 약속이 강력), 작가/회사 대면 태그라인은 **"작품은 작가가,
> 연결은 우리가"** 를 병기하는 **이중 브랜딩**. 단일안을 원하면 확장성 높은 **"취향으로 잇다"** 가 차선.

| 유료 광고(네이버/메타) | 신규 유입·전환 | `ad_copy` | 첫 줄에 핵심 이득 | CTR·CPI·ROAS |

> 위 채널들은 **외부 유입**(작가 마케팅) + **내부 발견**(소비자 큐레이션) 두 축을 동시에 키운다. 외부 채널의 콘텐츠가
> 만드는 작품 태그가 곧 내부 발견 피드의 매칭 인덱스가 된다([`curation-matching.md`](./curation-matching.md) §4).

## 5. 핵심 기능 — AI 콘텐츠 생성기 (5종+)

각 콘텐츠는 **입력(공방 정보 + 작품 사진/설명 + 페르소나 + 채널 옵션) → 출력(JSON)** 구조. 작품 사진은 **멀티모달
비전 단계**를 거쳐 "시각 브리프"로 변환된 뒤 카피에 반영된다(art의 품질 핵심 — [`copywriting-engine.md`](./copywriting-engine.md) §2).

| kind | 콘텐츠 | 입력 핵심 | 출력 | 주 사용 작가 페르소나 |
|---|---|---|---|---|
| `landing_detail` | **상세페이지** | 작품사진·스펙·가격·타깃 | 헤드라인+본문(문제→이득→증거→CTA) | A2 |
| `instagram_caption` | **인스타 캡션·해시태그** | 작품사진·무드 | 캡션(첫 줄 후킹)+해시태그 세트 | A1·A3 |
| `naver_blog` | **네이버 블로그** | 주제·작품사진·SEO 키워드 | 제목+1,500자+ 본문(정보형)+CTA | A2·A4 |
| `smartstore_detail` | **스마트스토어 상품 상세** | 작품사진·스펙·옵션 | 상품명+상세 구획(소재·사용·배송·신뢰) | A2 |
| `customer_message` | **단골 고객 메시지** | 목적(모집/안내/리마인드)·동의여부 | 합법 문구(정보성/광고성 분기) | A4 |
| `ad_copy` | **광고 카피** | 작품사진·목표·채널(네이버/메타) | 헤드라인 N개+본문(첫 줄 이득) | A2 |

> 페르소나 정의는 [`curation-matching.md`](./curation-matching.md) §1. **A1(고령 장인)** 은 콘텐츠 종류를 직접 고르지 않고 **사진만 →
> AI가 전부 대행**(저마찰 온보딩) → 위 5종을 자동 생성. 모든 출력은 `marketing_contents.output`(text) + `meta`(jsonb)에
> 저장하고, 생성 과정의 **시각 브리프 태그가 소비자 매칭 인덱스**로 함께 적재된다. `kind` 표준값은 위 표 그대로(드리프트 방지).

## 6. 데이터 모델 활용 (신규 테이블 불필요)

기존 `supabase/migrations/0001_init.sql`의 `marketing_contents`를 그대로 사용한다.

```
marketing_contents(
  id, store_id,
  kind   text,   -- 위 §5 표준값
  prompt text,   -- 실제 모델에 보낸 최종 프롬프트(재현·디버깅용)
  output text,   -- 생성 결과(JSON 문자열 또는 본문)
  meta   jsonb,  -- 아래 구조
  created_at, updated_at
)
```

**`meta` 권장 스키마**(엔진·모델 전략과 공유 — 단일 소스):

```jsonc
{
  "artist_persona": "A2",             // curation-matching.md §1
  "channel": "smartstore",            // §4
  "tone": "warm_artisan",             // 브랜드 보이스 프로파일 id
  "model": "gemini-3.5-flash",        // 실제 사용 모델 (ai-model-strategy.md)
  "vision_brief_id": "uuid|inline",   // 2단계 파이프라인 산출
  "match_tags": {                     // 소비자 매칭 인덱스 겸용 (curation-matching.md §3)
    "style": "내추럴", "mood": ["따뜻"], "color": ["크림"],
    "price_tier": "1-5만", "occasion": ["집들이","자기소장"], "values": ["수제"]
  },
  "vitale_checks": { "benefit": true, "emotion": true, "cta": true, "no_hype": true },
  "variant_group": "uuid",            // A/B 변형 묶음
  "compliance": { "ad_flag": true, "optout": true }  // customer_message 전용
}
```

> RLS·소유권은 기존 `is_store_owner()` 정책으로 충분(마이그레이션 변경 불필요). `match_tags`는 작품 단위 매칭에 쓰이며,
> Phase 3 소비자 발견 면에서 취향 프로파일과 대조된다([`curation-matching.md`](./curation-matching.md) §6).

## 7. 구현 로드맵

| 단계 | 범위 | 핵심 산출 |
|---|---|---|
| **Phase 2a (작가 PoC)** | 인스타 캡션 1종 + **비전 단계** + **저마찰 온보딩** | 사진→시각브리프(=매칭태그)→캡션, A1 walkthrough, 모델 라우팅 골격 |
| **Phase 2b (작가 확장)** | 5종 전체 + 대시보드 + **브랜드 보이스** + **매칭 태그 적재** | 생성 UI, 페르소나 분기, 컴플라이언스, 작품별 `match_tags` 표준 적재 |
| **Phase 3 (소비자 큐레이션)** | 소비자 계정·**취향 프로파일·임베딩·발견 피드** | "내가 찾던 예술" 매칭, 양면 RLS·노출 공정성 ([`curation-matching.md`](./curation-matching.md) §6) |
| (옵션) | 재생성·A/B 변형·내보내기·이미지 생성 | 카피 반복 루프, 카드뉴스 썸네일 |

- 각 단계 시작 전 **모델 효율/품질 비교 harness**([`ai-model-strategy.md`](./ai-model-strategy.md) §3)로 항목별 모델 검증.
- **진입 조건**: 소비자 큐레이션(3)은 작가·작품 **매칭 인덱스가 일정 규모 누적**된 뒤 의미 있음(공급 먼저 — 콜드스타트).

## 8. 컴플라이언스 요약 (상세는 copywriting-engine.md §5)

- **단골 메시지(광고성 정보)** — 정보통신망법: ① **사전 수신 동의** 전제(미동의 시 광고 문구 생성 차단) ② 제목/본문
  **(광고)** 표기 + **무료 수신거부** 수단 ③ **야간(21:00~익일 08:00) 전송 별도 동의** ④ **정보성 vs 광고성** 구분
  (단순 예약 안내 등 정보성은 동의 예외 가능, 단 판단을 사용자에게 떠넘기지 말고 분기 가이드 제공). 기존 거래관계는
  거래일로부터 6개월 예외 존재 — 단정하지 말고 동의 상태를 입력받아 분기.
- **작품 사진 저작권** — 업로드 사진은 원장님 본인 작품 전제. 타인 작품·도용 사진 경고 문구.
- **고객 PII** — `customers.phone`는 최소 수집·서버 전용. 생성 콘텐츠/로그에 PII 노출 금지.

> 출처: [정보통신망법 광고성 정보 가이드라인(핑거푸시)](https://developers.fingerpush.com/assemble/guide/ads) ·

## 9. 검증 / 성공 기준

- **작가 기능 품질**: 생성물 Vitale 체크(benefit·emotion·cta·no_hype) 통과율, 환각률(사진에 없는 속성 단정), 채널 규격 준수율.
- **저마찰(A1) 성공**: **고령 장인이 사진 1장만으로 발행까지 완주**하는 비율(막다른 단계 0), 사람 지원 호출률.
- **연결/큐레이션(목적 직결)**: 소비자 **발견→저장→구매** 전환, **매칭 만족도**("내가 찾던 예술"이었나), 작가별 도달 공정성.
- **모델 선택**: 항목별 harness 비교표([`ai-model-strategy.md`](./ai-model-strategy.md) §3) 결과로 확정.
- **제품 마케팅(도그푸딩)**: 우리 콘텐츠를 우리 엔진으로 생성 → 채널별 작가·소비자 유입 전환.

> 본 기획서는 문서 단계다. 실제 생성 품질은 **harness 실행(API 키·테스트 이미지 필요)** 으로 검증해야 하며 후속 작업이다.
