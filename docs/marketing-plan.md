# Hidden Factory 마케팅 기획서 — 공방 원장님을 위한 AI 마케팅 자동화

> 작성 전제(2026-06): 제품은 **공방 원장님(레진·도자기·회화·캘리그래피·유리·한지·기타)** 의 마케팅·고객 소통을
> **AI로 자동화**하는 B2B2C SaaS. 현재 auth + 온보딩 + DB 스키마만 있고 **핵심 기능(AI 콘텐츠 생성기)은 미구현**.
> 본 문서는 그 구현의 **청사진(기획서)** 이며, "마케팅의 신" 조 비테일(Joe Vitale)의 카피라이팅 관점으로 설계한다.
> 자매 문서: [`copywriting-engine.md`](./copywriting-engine.md)(프롬프트 엔진) · [`ai-model-strategy.md`](./ai-model-strategy.md)(모델 전략).

---

## TL;DR

- **누가**: 작품은 잘 만들지만 마케팅 글쓰기가 막막한 1인·소규모 공방 원장님.
- **무엇을**: 작품 사진 한 장 + 최소 정보 → **5종 마케팅 콘텐츠**(상세페이지·인스타·네이버 블로그·스마트스토어·단골 메시지·광고 카피)를 1분 만에.
- **왜 우리**: ① **작품을 "보고"** 쓰는 멀티모달 ② 조 비테일식 **이득(benefit) 중심 설득 카피** ③ **공방 고유 톤** 유지 ④ 채널 규격·**한국 법규(정보통신망법)** 자동 준수.
- **한 문장 포지셔닝**: **"원장님은 작품에만 집중하세요. 파는 글은 Hidden Factory가 1분 만에 씁니다."**

## 0. 공통 토대 — 제품이 서기 위한 전제

이 제품 자체가 "공방의 마케팅 도구"다. 따라서 **두 층위**가 있다:

1. **제품 마케팅**(우리가 공방 원장님을 모으는 활동) — §7 로드맵.
2. **제품 기능**(공방 원장님이 제품으로 만드는 콘텐츠) — §4~6 핵심.

본 기획서의 무게중심은 **2번(핵심 기능)** 이다. 1번은 "도그푸딩": 우리가 우리 엔진으로 우리 마케팅 콘텐츠를 만든다.

- **포지셔닝 한 문장**: "원장님은 작품에만 집중하세요. 파는 글은 Hidden Factory가 1분 만에."
- **3대 메시지 축**(모든 콘텐츠·기능은 이 중 하나에 귀속):
  1. **작품의 가치를 언어로** — 손으로 빚은 가치를 "사고 싶은 문장"으로 번역(hypnotic/benefit).
  2. **채널마다 자동 최적화** — 인스타·블로그·스토어·문자, 채널 규격과 톤을 알아서.
  3. **공방의 톤은 그대로** — 원장님 고유 목소리(브랜드 보이스)를 학습·유지.

## 1. 국내 공방 마케팅 시장 분석 (2025–26)

### 1.1 채널 지형 — "네이버 유입 × 인스타 × 스마트스토어 + AI/GEO"

- **3채널 통합이 기본값.** 고객이 어떤 경로로 검색하든 발견되도록 **네이버 유입 → 인스타 신뢰 → 스마트스토어 전환**을
  하나로 묶는 전략이 2026 소상공인 마케팅의 핵심.
- **네이버**: 블로그 체험단·인플루언서 포스팅은 자체 운영 대비 초기 노출 3~5배. **ADVoost(AI 쇼핑광고 자동화)** 로
  소재 없이도 예산만 넣으면 적합 사용자에게 노출. 스마트스토어 ↔ 크리에이터 제휴(쇼핑 커넥트).
- **인스타그램**: 릴스·**라이브커머스** 급성장. 공방은 "비하인드·제작 과정·완성 순간"이 강력한 시각 자산.
- **마이크로 인플루언서**: 대형 계정보다 진정성·신뢰도 높아 공방 타깃에 적합.
- **AI/GEO(Generative Engine Optimization)**: AI 검색엔진이 내 콘텐츠를 신뢰 출처로 인용하도록 최적화하는 흐름 부상.
  → 우리 생성 콘텐츠는 **사실 기반·구조화**(환각 배제)로 GEO 친화적이어야 한다.

### 1.2 공방 원장님의 페인포인트 (= 우리 제품의 정당성)

| 페인포인트 | 현실 | 우리 해법 |
|---|---|---|
| **시간 부족** | 제작·CS·재료 주문에 치여 글 쓸 시간 0 | 사진+클릭 → 1분 생성 |
| **글쓰기 막막함** | "예쁘다"는 알지만 "사고 싶게" 못 씀 | 조 비테일식 benefit 카피 엔진 |
| **채널마다 톤이 다름** | 인스타체·블로그체·상세페이지체 제각각 | 채널별 자동 최적화 |
| **법규 모름** | 단골 문자가 불법(미동의 광고)일 수 있음 | 정보통신망법 자동 준수 템플릿 |
| **일관성 붕괴** | 글마다 톤이 달라 브랜드가 흐릿 | 브랜드 보이스 프로파일 유지 |

## 2. 타깃 페르소나 (공방 원장님)

7개 `store_category`(레진·도자기·회화·캘리·유리·한지·기타)를 가로지르는 **4개 핵심 페르소나**. 각 페르소나는 서로
다른 콘텐츠 종류를 1순위로 필요로 한다 → 생성기 UX 분기의 근거.

| # | 페르소나 | 상황 | 핵심 목표 | 마찰(friction) | 1순위 콘텐츠 |
|---|---|---|---|---|---|
| P1 | **초보 1인 마케터** | 막 개업, SNS 계정만 있음 | 일단 꾸준히 올리기 | 뭘·어떻게 쓸지 막막 | 인스타 캡션·해시태그 |
| P2 | **노출은 되는데 전환 안 됨** | 팔로워는 있으나 판매 0 | "좋아요"→"구매" 전환 | 설득 카피 부재 | 상세페이지 · 광고 카피 |
| P3 | **클래스 모집형** | 원데이/정규 클래스가 주수입 | 정원 채우기 | 모집 글·리마인드 반복 | 단골 메시지 · 네이버 블로그 |
| P4 | **주문제작·판매형** | 스마트스토어/오더 중심 | 검색 유입·구매 전환 | SEO·상세 작성 부담 | 스마트스토어 상세 · 네이버 블로그 |

> 페르소나는 `meta.persona`로 저장되어 생성 톤·길이·CTA를 분기한다(상세 [`copywriting-engine.md`](./copywriting-engine.md)).
> 카테고리 라벨은 기존 `lib/schemas/onboarding.ts`의 `CATEGORY_LABELS`, 지역은 `lib/data/korea-regions.ts` 재사용.

## 3. 메시징 3-Pillar (조 비테일 관점)

조 비테일의 핵심 명제 **"매 사실을 말할 때마다 그것이 고객에게 주는 이득을 함께 말하라"** 를 제품의 뼈대로 삼는다.

1. **작품의 가치를 언어로 (Hypnotic / Benefit)** — feature("유광 마감")를 즉시 benefit("물때가 안 껴 설거지가 편한")으로 번역.
2. **채널마다 자동 최적화** — 같은 작품도 인스타(감성 후킹)·스토어(스펙+신뢰)·문자(짧고 따뜻)로 다르게.
3. **공방의 톤은 그대로** — 바넘의 "받은 값 이상을 줘라" = 콘텐츠마다 실질 가치(팁·스토리)를 얹어 신뢰 적립.

상세한 카피 원칙·프롬프트화는 [`copywriting-engine.md`](./copywriting-engine.md) 참조.

## 5. 핵심 기능 — AI 콘텐츠 생성기 (5종+)

각 콘텐츠는 **입력(공방 정보 + 작품 사진/설명 + 페르소나 + 채널 옵션) → 출력(JSON)** 구조. 작품 사진은 **멀티모달
비전 단계**를 거쳐 "시각 브리프"로 변환된 뒤 카피에 반영된다(art의 품질 핵심 — [`copywriting-engine.md`](./copywriting-engine.md) §2).

| kind | 콘텐츠 | 입력 핵심 | 출력 | 주 사용 페르소나 |
|---|---|---|---|---|
| `landing_detail` | **상세페이지** | 작품사진·스펙·가격·타깃 | 헤드라인+본문(문제→이득→증거→CTA) | P2 |
| `instagram_caption` | **인스타 캡션·해시태그** | 작품사진·무드 | 캡션(첫 줄 후킹)+해시태그 세트 | P1 |
| `naver_blog` | **네이버 블로그** | 주제·작품사진·SEO 키워드 | 제목+1,500자+ 본문(정보형)+CTA | P3·P4 |
| `smartstore_detail` | **스마트스토어 상품 상세** | 작품사진·스펙·옵션 | 상품명+상세 구획(소재·사용·배송·신뢰) | P4 |
| `customer_message` | **단골 고객 메시지** | 목적(모집/안내/리마인드)·동의여부 | 합법 문구(정보성/광고성 분기) | P3 |
| `ad_copy` | **광고 카피** | 작품사진·목표·채널(네이버/메타) | 헤드라인 N개+본문(첫 줄 이득) | P2 |

> 모든 출력은 `marketing_contents.output`(text) + `meta`(jsonb)에 저장. `kind` 표준값은 위 표 그대로(드리프트 방지).

## 6. 데이터 모델 활용 (신규 테이블 불필요)

기존 `supabase/migrations/0001_init.sql`의 `marketing_contents`를 그대로 사용한다.

```
marketing_contents(
  id, store_id,
  kind   text,   -- 위 §5 표준값
  prompt text,   -- 실제 모델에 보낸 최종 프롬프트(재현·디버깅용)
  output text,   -- 생성 결과(JSON 문자열 또는 본문)
  meta   jsonb,  -- 아래 구조
  created_at, updated_at
)
```

**`meta` 권장 스키마**(엔진·모델 전략과 공유 — 단일 소스):

```jsonc
{
  "persona": "P2",                    // §2
  "channel": "smartstore",            // §4
  "tone": "warm_artisan",             // 브랜드 보이스 프로파일 id
  "model": "gemini-3.5-flash",        // 실제 사용 모델 (ai-model-strategy.md)
  "vision_brief_id": "uuid|inline",   // 2단계 파이프라인 산출
  "vitale_checks": { "benefit": true, "emotion": true, "cta": true, "no_hype": true },
  "variant_group": "uuid",            // A/B 변형 묶음
  "compliance": { "ad_flag": true, "optout": true }  // customer_message 전용
}
```

> RLS·소유권은 기존 `is_store_owner()` 정책으로 충분(마이그레이션 변경 불필요).

## 7. 구현 로드맵

| 단계 | 범위 | 핵심 산출 |
|---|---|---|
| **Phase 2a (PoC)** | 인스타 캡션 1종 + **비전 단계** | 사진→시각브리프→캡션, `marketing_contents` 저장, 모델 라우팅 골격 |
| **Phase 2b (확장)** | 5종 전체 + 대시보드 + **브랜드 보이스 프로파일** | 생성 UI, 저장/조회, 페르소나 분기, 단골 메시지 컴플라이언스 |
| **Phase 2c (고도화)** | 재생성·**A/B 변형**·내보내기 + (옵션) **이미지 생성** | 카피 반복 루프, 카드뉴스 썸네일 자동 생성 검토 |

각 단계 시작 전 **모델 효율/품질 비교 harness**([`ai-model-strategy.md`](./ai-model-strategy.md) §3)로 항목별 모델을 검증·확정한다.

## 8. 컴플라이언스 요약 (상세는 copywriting-engine.md §5)

- **단골 메시지(광고성 정보)** — 정보통신망법: ① **사전 수신 동의** 전제(미동의 시 광고 문구 생성 차단) ② 제목/본문
  **(광고)** 표기 + **무료 수신거부** 수단 ③ **야간(21:00~익일 08:00) 전송 별도 동의** ④ **정보성 vs 광고성** 구분
  (단순 예약 안내 등 정보성은 동의 예외 가능, 단 판단을 사용자에게 떠넘기지 말고 분기 가이드 제공). 기존 거래관계는
  거래일로부터 6개월 예외 존재 — 단정하지 말고 동의 상태를 입력받아 분기.
- **작품 사진 저작권** — 업로드 사진은 원장님 본인 작품 전제. 타인 작품·도용 사진 경고 문구.
- **고객 PII** — `customers.phone`는 최소 수집·서버 전용. 생성 콘텐츠/로그에 PII 노출 금지.

## 9. 검증 / 성공 기준
