# (제안) 천안 공예 작가–시민 연결 플랫폼 "Hidden Factory" — 사업계획서

> 제안 주체: **천안공예협회**(협회장 직접 제안) · 대상: **천안문화재단 · 천안시청** · 운영: 개발·플랫폼 팀.
> 성격: **공모 응모가 아니라**, 오래되고 권한 있는 협회가 재단에 **직접 제안하는 관계 기반 협력 사업**. 기존 지원사업을
> **대체가 아니라 활성화**하는 저비용 연결 레이어.
> ⚠️ **확인 필요(제출 전)**: 아래 기존 사업·통계의 현행 수치는 천안시청(기업지원과 041-521-5460)·
> 천안문화재단·[아트누리](https://www.artnuri.or.kr/)·[bizinfo](https://www.bizinfo.go.kr)에서 확정할 것. 본안은 초안이며 법률 검토 권장.

## ⚡ 1page 요약 (Executive Summary)

- **제안 성격**: 지역 공예를 오래 대표해 온 **천안공예협회가 천안문화재단에 직접 제안하는 지역 협력 사업**. 협회의 역사·권위·
  작가 네트워크가 사업의 신뢰 기반이고, 운영(시스템·인터뷰·큐레이션)은 협력 팀이 맡는다.
- **무엇**: 천안 공예 작가(특히 **고령 장인**)를 시민·관광객과 **초개인화로 연결**하는 플랫폼. 작가는 **인터뷰 1회 + 작품 사진**만,
  나머지(소개글·스토리·태그·발행·소비자 연결)는 **AI + 우리가 대행** → 작가는 작품에만 집중.
- **왜 지금**: 소상공인 54.8%가 50대 이상, 고령층 다수가 온라인 판로·마케팅에서 소외. 기존 지원사업(바우처·교육·박람회)은
  **"작가가 직접 해야 해서" 고령 장인이 받아도 못 쓰고, 일회성이라 지속되지 않는다.**
- **차별(기존 사업 활성화)**: 지원사업이 만든 자산(상세페이지·영상·입점)을 **지속적으로 소비자와 연결·운영** → 기존 투자 ROI를 끌어올림.
- **기관 요청**: ① 시범사업 예산 연계·공동 추진 ② 업무협약·행사·홍보 연계 ③ **관공서 기념품·기업 답례품·관광 굿즈 단체수요** ④ 재단·시청의
  **시민 도달망을 소비자 유입 채널로** 활용.
- **기대효과**: 지역 공예 생태계 활성화, 고령 장인 디지털 포용, 관광·로컬소비 연계, 측정 가능한 매칭·매출 성과.
- **시작은 천안, 검증 후 인근 지역 확장.**

## 1. 추진 배경 (Problem)

- **고령 장인의 디지털 격차**: 소상공인 54.8%가 50대 이상, 고령층 30%가 앱 사용에 미숙([근거](https://www.kca.go.kr/home/board/download.do?menukey=6102&fno=10037209&bid=00000160&did=1003436954)).
  손기술은 최고지만 온라인 판로·마케팅·콘텐츠 제작은 막막.
- **기존 지원사업의 한계(빈틈)** — *확인 필요, 아래는 공개정보 기반 가설*:
  1. **일회성**: 박람회 참가·교육·바우처는 끝나면 작가는 다시 혼자. 지속 운영 주체 부재.
  2. **"받아도 못 쓰는" 구조**: 온라인 판로 바우처도 결국 **작가가 직접** 스토어·콘텐츠·마케팅 → 고령 장인 실행 실패.
  3. **청년 편중**: 일부 창작 지원은 청년 한정(예: K-Art) → 고령 장인 사각지대.
  4. **공급만, 수요 연결 부재**: "내보내기(입점·전시)"는 하나 **맞는 소비자와의 지속 매칭·발견**이 없음.
  5. **분절**: 교육·입점·전시·홍보가 따로 놂 — 통합 운영자 없음.
- **결과**: 좋은 작품이 만들어져도 **맞는 소비자를 못 만나고**, 작가는 마케팅에 지쳐 작품활동이 위축된다.

## 2. 사업 목적 (Goal)

천안 공예 작가와 시민·관광객을 **초개인화 큐레이션으로 연결**하여, ① 작가는 작품에만 집중하고 ② 시민은 "내가 찾던 예술"을
발견하며 ③ **기존 지원사업의 성과를 지속·활성화**한다.

## 3. 사업 내용 (Solution)

- **작가(공급)**: 협회 작가를 **1:1 인터뷰**(화상 기본·작가 선택). 인터뷰 영상은 **작가 소개 페이지**에 싣고, 인터뷰·사진에서
  소개글·스토리·검색태그·가격제안을 **AI가 추출·작성**. 작가의 평생 업무는 **인터뷰 + 사진 업로드 + 마일스톤(전시·수상) 추가 인터뷰**뿐.
- **시민·관광객(수요)**: 취향 기반 **개인화 발견 피드**로 작가·작품을 추천. 작가의 손맛·서사(인터뷰 영상)를 전면에 → 감정 연결.
- **거래(단계적)**: 출시기엔 **발견·연결(리드젠)** — 구매는 작가의 기존 채널로 연결(결제·배송 부담 없이 빠른 시작). 검증 후
  플랫폼 내 거래로 확장.
- **기존 자산 활성화**: 지원사업으로 만든 상세페이지·영상·입점 정보를 가져와 **지속 노출·매칭**에 재활용.

## 4. 기관 요청 사항 (Ask)

1. **시범사업 예산 연계·공동 추진**: 천안 파일럿(작가 인터뷰·플랫폼 운영) 비용을 재단 예산·기존 사업과 연계. *적은 예산으로 다수 작가·시민 연결.* (공모 응모가 아닌 협회–재단 직접 협력)
2. **업무협약(MOU)·행사·홍보 연계**: 재단 전시·축제(예: 흥타령춤축제)·관광지에 **QR로 작가 발견** 연결, 시·재단 채널 홍보.
3. **단체·굿즈 수요 연계**: 관공서 기념품·기업 답례품·관광 굿즈를 협회 작가와 매칭(공급에 즉시 매출, 플랫폼 가치 입증).
4. **시민 도달망 = 소비자 유입 채널**: 시·재단의 시민·관광 홍보망을 통해 초기 소비자 확보(수요측 리스크 최소화).

## 5. 지역 기여 (Why the city/foundation should care)

- **지역 공예 생태계 활성화**: 작가 매출·지속 노출, 신진·고령 작가 균형 노출.
- **디지털 포용·고령 친화**: "받아도 못 쓰던" 고령 장인을 실제 작동하게 — 정책 사각지대 해소.
- **관광·로컬소비 연계**: 천안 방문객을 지역 공예 구매·체험으로 연결, 도시 브랜드 강화.
- **기존 투자 ROI 제고**: 이미 집행된 교육·입점·전시 성과를 지속 매출로 전환.

## 6. 추진 체계 (Governance)

- **제안·주관**: 천안공예협회(협회장) — **수십 년 지역 공예 대표성·권위·작가 네트워크**가 사업 신뢰의 핵심 자산. 작가 섭외·검증·지역 신뢰.
- **운영**: 개발·플랫폼 팀 — 시스템·인터뷰·큐레이션·콘텐츠 대행.
- **후원·연계**: 천안문화재단·천안시청 — 예산 연계·공간·홍보·시민 도달망. *(역할·정산 최종 구도는 협회–재단 협의로 확정.)*
- **데이터·권리**: 작가 인터뷰 영상·작품 사진은 **활용 동의** 후 사용, 이탈 시 내림. 시민 개인정보는 최소 수집·법규 준수.

## 7. 추진 일정 (예시 — 확정 시 조정)

| 단계 | 기간(예) | 내용 |
|---|---|---|
| 준비 | 1~2개월 | 협약·법무(약관·개인정보·중개 고지), 작가 N명 1차 인터뷰, 플랫폼 파일럿 |
| 파일럿 | 3~4개월 | 천안 작가 큐레이션·소비자 발견 v1, 행사 QR·단체수요 1건 이상 |
| 평가·확장 | 이후 | 성과 측정 → 인근 지역 확장, 플랫폼 거래 전환 검토 |

## 8. 소요 예산 (항목 — 금액은 협의/공모 기준 확정)

| 항목 | 내용 |
|---|---|
| 인터뷰·영상 | 작가 인터뷰 진행·영상 편집·저장 |
| 플랫폼 운영 | 개발·서버·AI 사용료·콘텐츠 제작 대행 |
| 홍보·행사 | 시민 대상 홍보, 행사 연계 부스/QR |
| 운영 인력 | 큐레이션·작가 지원(전화/카톡)·CS |

> 구체 금액은 **재단과 협의할 규모**로 산정(공모 양식 아님). "적은 비용으로 다수 작가·시민 연결"을 핵심 가치제안으로.

## 9. 성과지표 (KPI)

- 참여 작가 수, 작가당 노출·문의·매출(연결), 인터뷰 영상 조회.
- 시민 발견→저장→구매(연결) 전환, **매칭 만족도("내가 찾던 예술")**.
- 단체·굿즈 수요 건수·금액. 기존 지원사업 자산 재활용·활성화 건수.

## 10. 지속가능성 (Sustainability)

- 초기: 보조금/공모 + 단체수요로 운영. 검증 후: 플랫폼 내 거래 수수료(마켓플레이스 전환)·B2G 반복.
- 천안 모델 표준화 → **인근 시군·타 지역 협회로 확장**(같은 구조 복제).
