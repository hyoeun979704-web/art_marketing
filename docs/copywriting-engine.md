## 1. 조 비테일 프레임워크 (카피의 철학)

근거: Joe Vitale, *Hypnotic Writing*(2007) · *There's a Customer Born Every Minute*(P.T. 바넘 10원칙, 2006).
([AWAI Joe Vitale](https://www.awai.com/bio/joe-vitale/) · [Hypnotic Writing(Wiley)](https://www.wiley.com/en-us/Hypnotic+Writing%3A+How+to+Seduce+and+Persuade+Customers+with+Only+Your+Words-p-9780470009796) ·
[There's a Customer Born Every Minute](https://www.amazon.com/Theres-Customer-Born-Every-Minute/dp/0814479537))

### 1.1 다섯 가지 작동 원칙 (엔진에 항상 적용)

1. **사실→이득 강제 (Benefit Translation)** — 비테일의 제1원칙: *"매 사실을 말할 때마다 그 사실이 상대에게 주는
   이득을 함께 말하라."* 모든 feature는 즉시 benefit으로 번역. (예: "유광 유약" → "물때가 안 껴 설거지가 편한 유광 마감")
2. **AIDA 골격** — Attention(첫 줄 후킹) → Interest(공감·문제) → Desire(이득·시각화) → Action(명확한 CTA).
3. **감정·시각화 (Hypnotic)** — 독자의 머릿속에 그림을 그린다. 오감·장면·"당신이 ~하는 순간" 화법. embedded
   command(부드러운 명령: "상상해 보세요", "느껴 보세요")와 copy connector(연결어: "그래서", "게다가", "바로 그때")로 흐름 유지.
4. **바넘 — 받은 값 이상을 줘라** — 모든 콘텐츠에 **실질 가치 한 조각**(관리 팁·제작 비하인드·사용 아이디어)을 끼워
   신뢰를 적립. 팔기만 하는 글은 금지.
5. **진정성 우선 (한국형 신뢰)** — 과장·낚시는 단기 클릭은 얻어도 공방의 생명인 신뢰를 깎는다. "솔직·경험형" 톤이 기본.
6. **작가 서사 전면 (스토리텔링 > 나열)** — 핸드메이드 시장의 전환은 **작가-소비자 감정 연결**에서 온다(상품 스펙
   나열=idus 차별점). 작품 카피마다 **손맛·제작 과정·작가의 의도** 한 조각을 녹인다. 맥락(라이프스타일) 장면을 그린다.

### 1.2 한국 시장 가드레일 (하드 룰 — 위반 시 생성 거부/수정)

- **효능·치료·과학 단정 금지** (예: "스트레스가 사라집니다", "미세먼지 99% 차단" 등 근거 없는 단정).
- **최상급·허위 단정 금지** ("국내 유일", "최고", "1등) — 객관 근거 없으면 사용 불가.
- **사진에 없는 속성 단정 금지**(환각 차단, §2.3).
- **과대광고체 회피** — 느낌표 남발·자극 낚시 대신 차분한 신뢰형.
- **단골 메시지 법규** — §5(정보통신망법) 강제.

## 2. 2단계 멀티모달 파이프라인 (art의 품질 핵심)

작품은 시각·감성의 산물이다. 모델이 작품을 **"보지" 않고** 텍스트만으로 쓰면 (a) 감성·구체성이 죽고 (b) 환각이 는다.
따라서 생성은 **항상 2단계**다.

### 2.1 Stage 1 — Vision: 작품 사진 → 시각 브리프

- **입력**: 작품 사진(1~N장) + (선택) 원장님 한 줄 설명.
- **모델**: 멀티모달 강세 모델(권고: Pro급 — [`ai-model-strategy.md`](./ai-model-strategy.md) §2).
- **출력 — 구조화 시각 브리프(JSON)**:

```jsonc
{
  "category_guess": "POTTERY",
  "colors": ["크림 화이트", "유약 청록 포인트"],
  "texture": "매트한 표면에 손가락 자국이 남은 핸드빌드 질감",
  "form": "살짝 비대칭인 머그, 둥근 손잡이",
  "technique": ["물레 성형", "이중 유약"],
  "mood": ["따뜻함", "내추럴", "수수함"],
  "details": ["입구 살짝 외반", "굽 노출 마감"],
  "use_scenes": ["아침 커피", "선물"],
  "uncertain": ["용량은 사진으로 단정 불가"]   // 모델이 확신 못 하는 것 → 카피에서 단정 금지
}
```

- **하드 룰**: 보이지 않는 것은 `uncertain`에. **추측을 사실처럼 쓰지 않는다.**
- **매칭 인덱스 겸용** ★: 시각 브리프는 카피 입력일 뿐 아니라 **소비자 큐레이션 매칭 인덱스**다. `colors→color`,
  `mood→mood`, `category_guess→category`, `use_scenes→occasion`, (스타일 추정)`→style`로 [`curation-matching.md`](./curation-matching.md)
  §3 택소노미와 **동일 명칭**으로 정렬해 출력한다. 즉 한 번의 비전 분석이 ① 마케팅 카피 ② 소비자 매칭을 동시에 만든다.

### 2.2 Stage 2 — Copy: 시각 브리프 → 콘텐츠

- **입력**: 시각 브리프 + **작가 인터뷰 발췌(작가 실제 발화)** + 공방 정보(이름·카테고리·지역) + **브랜드 보이스 프로파일**(§6) + 페르소나 + 채널/옵션.
- **모델**: 채널 난도에 따라 라우팅([`ai-model-strategy.md`](./ai-model-strategy.md) §2).
- **출력**: 채널별 JSON(§4).
- **작가 목소리 보존 (★동질화 방지 — 바튼)**: 스토리·맥락의 **소스 오브 트루스는 작가 인터뷰**다([`curation-matching.md`](./curation-matching.md) §5.2).
  AI는 인터뷰에서 작가의 **실제 표현·어휘·서사**를 살려 쓰고, 모든 작가를 똑같은 "최면 카피" 톤으로 납작하게 만들지 않는다.
  인터뷰에 없는 미사여구로 채우기 금지.
- **저마찰 (A1 평균 50대)**: 작가 입력은 **사진(촬영·업로드) + 인터뷰(말하기)** 뿐. 부족한 정보는 AI가 시각 브리프·인터뷰로
  **합리적 기본값**을 채우고 긴 폼은 강요하지 않는다. 나머지는 우리/AI 대행 — 작가는 작품활동에 집중([`curation-matching.md`](./curation-matching.md) §5.1).

### 2.3 환각 가드레일 (전 단계 공통)

- 카피의 모든 사실 주장은 **시각 브리프·작가 인터뷰·사용자 입력에 근거**해야 한다. 근거 없으면 생성하지 말 것.
- `uncertain` 항목은 단정 대신 **부드러운 표현**("~한 느낌의")으로만 사용하거나 생략.
- 가격·용량·소재 성분 등 **검증 가능한 수치**는 사용자 입력이 있을 때만 기재.

## 3. 공용 시스템 프롬프트 (베이스)

모든 콘텐츠 생성의 Stage 2 시스템 프롬프트 골격. `{{...}}`는 런타임 주입 슬롯.

```text
당신은 한국 공방 "{{store_name}}"({{category_label}}, {{region}})의 전속 카피라이터입니다.
당신의 글쓰기 철학(반드시 지킴):
1) 사실→이득: 작품의 특징을 말할 때마다 그것이 고객에게 주는 구체적 이득을 함께 쓴다.
2) AIDA: 첫 문장으로 시선을 잡고(Attention), 공감으로 끌고(Interest), 갖고 싶게 만들고(Desire), 행동을 청한다(Action).
3) 머릿속에 그림을 그린다: 오감과 장면, "당신이 ~하는 순간" 화법을 쓴다.
4) 받은 값 이상: 글마다 작은 실질 가치(관리 팁/사용 아이디어/비하인드)를 하나 끼운다.
5) 진정성: 과장·최상급·효능 단정·낚시를 쓰지 않는다. 차분하고 솔직한 신뢰형 톤.

브랜드 보이스: {{brand_voice}}      // 예: 따뜻하고 담백, 반말 금지, 이모지 절제
타깃 페르소나: {{persona_desc}}
근거(시각 브리프): {{vision_brief_json}}
하드 룰: 시각 브리프/입력에 없는 사실을 지어내지 말 것. uncertain 항목은 단정 금지.
출력: 아래 JSON 스키마를 정확히 따를 것(추가 설명 금지).
{{channel_module}}   // §4 채널별 모듈 주입
```

> 구현 메모: Gemini의 구조화 출력(JSON mode/`responseSchema`)으로 스키마를 강제. `prompt`(최종 프롬프트)와 `output`을
> `marketing_contents`에 저장(재현·디버깅·harness 채점용).

## 4. 콘텐츠 5종별 프롬프트 모듈

각 모듈 = **입력 스키마 · 채널 제약 · Vitale 적용 규칙 · 출력 JSON · 품질 체크리스트**. `kind` 값은 [`marketing-plan.md`](./marketing-plan.md) §5와 동일.

### 4.1 `landing_detail` — 상세페이지 (A2)
- **입력**: 시각브리프, 작품명, 가격(선택), 핵심 셀링포인트, 타깃.
- **제약**: 스크롤 구조(헤드라인 → 공감 → 이득 → 증거/디테일 → CTA). 길이 중간(400~800자).
- **Vitale 규칙**: 구조 = **문제→이득→증거→CTA**. 헤드라인은 benefit 1개로. 디테일마다 사실→이득 변환.
- **출력**: `{ "headline": str, "sections": [{"label": str, "body": str}], "cta": str }`
- **체크리스트**: 헤드라인에 이득? / 모든 스펙이 이득으로 번역? / 증거(소재·제작·후기 유도)? / CTA 1개 명확? / 과장 없음?

### 4.2 `instagram_caption` — 인스타 캡션·해시태그 (A1·A3)
- **입력**: 시각브리프, 무드/이벤트(신상·재입고·클래스), 톤.
- **제약**: 첫 줄(=미리보기) 후킹 필수. 본문 짧게(2~5문장). 해시태그 **10~20개**(대형+중형+로컬+브랜드 믹스).
- **Vitale 규칙**: 첫 줄 = Attention(질문/장면). embedded command 1개("저장해 두세요"). 저장·공유 유발.
- **출력**: `{ "caption": str, "first_line": str, "hashtags": [str] }`
- **체크리스트**: 첫 줄 후킹? / 감정·장면? / 해시태그 믹스 적정? / 과한 이모지/낚시 없음? / 행동 유도(저장/DM)?

### 4.3 `naver_blog` — 네이버 블로그 (A2·A4)
- **입력**: 주제, SEO 키워드(1~3), 시각브리프, 공방 스토리(선택).
- **제약**: **1,500자+**, 정보형 70% : 공방 30%. 제목 앞단에 핵심 키워드. 소제목 4~6. 이미지 자리 표시.
- **Vitale 규칙**: 바넘 "받은 값 이상" = 실용 정보(예: "도자기 관리법 5")로 신뢰 먼저, 공방은 자연 삽입 + 하단 CTA.
  GEO 친화: 사실 기반·구조화·Q&A 소제목.
- **출력**: `{ "title": str, "sections": [{"heading": str, "body": str}], "image_slots": [str], "cta": str, "keywords": [str] }`
- **체크리스트**: 키워드 제목 앞단? / 1,500자+? / 정보:홍보 = 7:3? / 단정/과장 없음? / GEO 구조(소제목/요약)?

### 4.4 `smartstore_detail` — 스마트스토어 상품 상세 (A2)
- **입력**: 시각브리프, 옵션/사이즈, 소재, 배송/교환 정보, 가격.
- **제약**: 구획 고정(한눈 요약 → 작품 소개 → 소재·사이즈 → 사용/관리 → 배송/교환 → 신뢰 요소). 검색 키워드 자연 포함.
- **Vitale 규칙**: 스펙마다 사실→이득. "신뢰 요소"(수제·소량·검수)로 안심. 구매 직전 불안(파손·교환) 선제 해소.
- **출력**: `{ "product_name": str, "summary": str, "blocks": [{"label": str, "body": str}], "search_terms": [str] }`
- **체크리스트**: 구획 완비? / 스펙→이득? / 구매 불안 해소? / 검색어 자연 삽입? / 과장 없음?

### 4.5 `customer_message` — 단골 고객 메시지 (A4) — **§5 컴플라이언스 필수**
- **입력**: 목적(클래스 모집/예약 안내/재방문 유도/완성 알림), **수신동의 여부**, 발송 시간대, 채널(문자/카톡/DM).
- **제약**: 짧게(문자 1~3문장), 따뜻한 1:1 톤. **광고성이면 §5 규칙 강제**.
- **Vitale 규칙**: 관계 우선("지난번 ~ 감사했어요") → 이득 제안 → 부담 없는 CTA. 받은 값 이상(작은 혜택/팁).
- **출력**: `{ "message": str, "is_ad": bool, "compliance": {"ad_prefix": str|null, "optout": str|null, "night_ok": bool} }`
- **체크리스트**: §5 전부 충족? / 정보성/광고성 올바로 분기? / 따뜻함? / 길이 적정? / 미동의 시 광고문구 차단됨?

### 4.6 `ad_copy` — 광고 카피 (A2)
- **입력**: 시각브리프, 목표(전환/유입), 채널(네이버/메타), 글자수 제약.
- **제약**: 채널 규격(예: 헤드라인 길이). **첫 줄/첫 5초에 핵심 이득 + 무엇인지** 노출. 변형 N개.
- **Vitale 규칙**: 한 광고 = 한 메시지. 첫 줄 benefit. 강한 CTA. 과장 금지(플랫폼 심사·신뢰).
- **출력**: `{ "headlines": [str], "primary_texts": [str], "cta": str, "variant_group": str }`
- **체크리스트**: 첫 줄 이득? / 단일 메시지? / 규격 글자수? / 과장/금지표현 없음? / 변형 간 차별?

## 5. 단골 메시지 컴플라이언스 모듈 (정보통신망법)

`customer_message`가 **광고성**일 때 강제되는 하드 룰. 위반 시 생성 거부 또는 자동 보정.

| 규칙 | 적용 |
|---|---|
| **사전 수신 동의** | `consent=false`면 **광고 문구 생성 차단**(정보성만 허용). UI에서 동의 상태 입력받음. |
| **(광고) 표기** | 광고성 메시지는 본문 머리에 `(광고)` + 발신자(공방명) 명시. |
| **무료 수신거부** | 무료 거부 수단(번호/링크) 문구 포함. |
| **야간 전송 제한** | 21:00~익일 08:00 발송은 별도 동의 필요 → `night_ok=false`면 그 시간대 발송 경고/차단. |
| **정보성 vs 광고성** | 단순 예약/완성 안내(정보성)는 동의 예외 가능. **혜택·할인·신상 홍보가 섞이면 광고성**으로 분기. 모호하면 광고성으로 간주(보수적). |

> 거래관계 6개월 예외 등 세부는 동의 상태·거래일 입력으로 분기하되, **단정하지 말고** 보수적 기본값(광고성=동의 필요)으로.
> 근거: [핑거푸시 광고성 정보 가이드라인](https://developers.fingerpush.com/assemble/guide/ads) ·
> [정보성 vs 광고성(dfinery)](https://docs.dfinery.ai/user-guide/action/off-site-campaign/info-vs-ads) ·

## 6. 브랜드 보이스 프로파일 (시간축 일관성)

같은 공방의 콘텐츠가 글마다 톤이 다르면 브랜드가 흐려진다. → **공방별 톤 프로파일**을 1회 도출해 매 프롬프트에 주입.

- **도출**: 온보딩 입력(카테고리·태그라인·SNS 톤) + **사용자가 "채택"한 과거 생성물**에서 톤 요약(formality·이모지·길이·금지어).
- **저장**: `stores`(또는 `marketing_contents.meta.tone`이 참조하는 프로파일). 신규 컬럼이 필요하면 별도 마이그(이번 범위 밖, 로드맵 2b).
- **주입**: §3의 `{{brand_voice}}` 슬롯.

## 7. 재생성·변형(A/B) 루프

비테일의 카피는 **반복으로 완성**된다. 생성기는 단발이 아니라 반복을 지원.

- **재생성(피드백)**: "더 짧게/더 따뜻하게/이득 강조" 등 사용자 지시를 시스템 프롬프트에 추가해 재호출.
- **변형(A/B)**: 동일 입력으로 N개 변형 생성, `meta.variant_group`으로 묶음 → 사용자가 채택. 채택 데이터는 §6 보이스 학습에 환류.

## 8. few-shot 예시 (구현 시 모듈에 주입)

### 예시 A — 도자기 머그 → `instagram_caption`
- **시각브리프(요약)**: 크림 화이트 매트 머그, 핸드빌드 질감, 둥근 손잡이, 무드=따뜻/내추럴.
- **모범 출력**:
```json
{
  "first_line": "손에 쥐는 순간, 아침이 조금 느려집니다.",
  "caption": "손에 쥐는 순간, 아침이 조금 느려집니다.\n물레로 하나씩 빚어 손가락 자국이 그대로 남았어요. 매트한 표면이 미끄럽지 않아 따뜻한 커피를 오래 들고 있기 좋아요. 똑같은 게 하나도 없는 게 핸드메이드의 매력이죠.\n\n오늘 입고분은 6개뿐이에요. 마음에 드는 결을 골라보세요 🤍 (저장해 두면 다음 입고 때 비교하기 좋아요)",
  "hashtags": ["#도자기머그","#핸드메이드","#공방","#수제도자기","#커피잔","#홈카페","#도예","#오브제","#집들이선물","#OO동공방"]
}
```
- **Vitale 체크**: 첫 줄=장면 후킹 / "매트 표면(사실)→안 미끄러워 오래 들기 좋음(이득)" / 희소성 / "저장" embedded command / 과장 없음. ✅

### 예시 B — 레진 코스터 → `smartstore_detail`(요약)
- **시각브리프(요약)**: 투명 블루 그라데이션, 금박 포인트, 매끈 마감, 원형.
- **모범 출력 골자**: 상품명(검색어 포함) → 요약(이득) → 소재/사이즈 → "물잔 자국 걱정 없는 매끈 코팅(사실→이득)" →
  배송/교환(파손 선제 안심) → 신뢰("소량 수제·전수 검수"). 과장·효능 단정 없음. ✅

## 9. 자기 검증 체크리스트 (생성 후 모든 콘텐츠 공통)

1. **사실→이득** 변환됨? (특징 나열에 그치지 않음)
2. **감정/시각화** 있음? (머릿속 그림)
3. **채널 규격** 준수? (길이·해시태그·구획·글자수)
4. **환각 없음**? (시각브리프/입력에 근거, uncertain 단정 안 함)
5. **과장·효능·최상급 없음**? (한국 가드레일)
6. **CTA** 존재·명확?
7. **브랜드 톤** 유지?
8. (`customer_message`) **§5 컴플라이언스** 충족?

> 이 8항목은 `meta.vitale_checks`/`meta.compliance`로 기록하고, [`ai-model-strategy.md`](./ai-model-strategy.md) §3 harness의 채점 루브릭과 동일하게 쓴다(단일 소스).
