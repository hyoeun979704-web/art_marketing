# 출시·운영 준비 전수조사 (Launch Readiness Audit)

> 작성 2026-06. "실제 출시·운영에 구멍이 없는지" 전수조사 + 할일 체크리스트. 코드/스키마 실측 기반.
> **비치헤드: 천안공예협회**(협회장 주도·작가 니즈 검증됨·협회 내 작가 직접 섭외). **천안 시작 → 지역 확장.**
> 거래 구조: **단계적 — 리드젠(출시) → 마켓플레이스(확장)**. 표기: **[맹점]=기획서에도 없던 것** / **[미구현]=기획엔 있으나 코드 0**.
> 관련: [`marketing-plan.md`](./marketing-plan.md) · [`curation-matching.md`](./curation-matching.md) · [`copywriting-engine.md`](./copywriting-engine.md) · [`ai-model-strategy.md`](./ai-model-strategy.md) · [`proposal-cheonan.md`](./proposal-cheonan.md).

## TL;DR

코드는 **인증 + 작가 온보딩 + 빈 스키마**까지만 실재. 기획서가 그린 거의 전부(생성기·큐레이션·소비자·인터뷰·커머스)는
미구현 → **현 상태 출시 불가.** 단, **천안공예협회 비치헤드**가 시장 리스크(공급 콜드스타트·니즈 검증·신뢰)를 크게
줄여준다. 따라서 남는 진짜 구멍은 **법무 표면·소비자 경험 구현·AI 발행 검수·관측**이다.

## 0. 비치헤드가 해소하는 리스크 (다운그레이드)

| 원래 우려 | 천안공예협회로 해소되는 정도 |
|---|---|
| 공급 콜드스타트(작품 부족) | ✅ 대부분 해소 — 협회 내 작가 직접 섭외로 시드. |
| 작가 니즈 검증 | ✅ 해소 — 협회장 주도, 니즈 확인된 프로젝트. |
| 인터뷰 throughput 병목 | ✅ 초기 해소 — 천안 한정 규모라 1:1 화상/대면 인터뷰 충분히 감당. (전국 확장 시 재점검) |
| 작가 신뢰·도용 리스크 | 🟡 완화 — 협회 검증 회원 중심이라 초기 낮음(확장 시 정책 필요). |
| 수요측 GTM(작가 모집) | ✅ 초기 해소 — 협회 네트워크. (소비자 획득은 여전히 필요 — H) |

> **함의**: "전국 마켓플레이스"가 아니라 **천안 지역 파일럿**으로 좁고 깊게 검증 → 인접 확장. 초기엔 **컨시어지/수작업 MVP**
> (우리가 천안 작가 손수 큐레이션, 구매는 작가 채널 연결)로도 출시 가능.

## 🔴 P0 — 출시 차단 (비치헤드로도 안 사라지는 구멍)

### B. 법무·컴플라이언스 표면 [맹점] — 소규모 파일럿도 필수
- [ ] **개인정보처리방침 / 이용약관 / 사업자정보 표시**(`/privacy`·`/terms`·`/legal`) — 현재 전무. 소비자 1명만 받아도 필요.
- [ ] **통신판매중개업 신고 + 중개자 면책 고지**(리드젠). 마켓플레이스 전환 시 통신판매업 요건 추가.
- [ ] **개인정보보호법**: 수집 동의 UI·스키마, `customers.phone` **평문→보호**, 보관·파기·열람/삭제(§35), 처리 audit.
- [ ] **표시·광고법**: AI 카피 효능·과장 단정 방지 + **발행 전 사람 검수 게이트**(E).
- [ ] **초상권·인터뷰 활용 동의**: 작가 영상 사용범위·이탈 시 내림. 작품 사진 저작권/진본 확인.
- [ ] 정보통신망법(메시지 기능 시): 동의·(광고)표기·무료거부·야간차단 — 기획서 §5만 있고 미구현 [미구현].

### C. 소비자 경험 (북극성) — 0% 구현 [미구현]
- [ ] 소비자 계정·역할(작가/소비자/관리자 — 현재 구분 없음).
- [ ] 취향 온보딩(콜드스타트 퀴즈)·취향 프로파일 스키마(미존재).
- [ ] 개인화 발견 피드·검색·작품 상세·**작가 소개 페이지(인터뷰 영상)**.
- [ ] 작품 매칭 태그(`artworks.match_tags` 또는 별도 테이블)·인덱싱.

## 🟠 P1 — 운영 품질·확장 대비

### D. 작가 인터뷰 운영 (천안 규모 OK, 확장 대비) [부분]
- [ ] **영상 편집 파이프라인·SLA·비용**, 영상 저장/CDN, 전사. 스키마 `artist_interviews(video_url, transcript, extracted_story, brand_voice)` 신설.
- [ ] 인터뷰어 캐파·일정(천안 한정 감당 / **인접 확장 시 인터뷰어 네트워크** 계획).

### E. AI 운영·품질·책임 [부분 맹점]
- [ ] **모델 품질 harness 실행**(현재 권고만). `lib/gemini.ts` 미호출.
- [ ] **발행 전 사람 검수 게이트**(표시광고법 책임 차단) + 환각/금지표현 모더레이션.
- [ ] Gemini **비용 통제·rate limit**.

### F. 데이터·인프라·관측 [맹점]
- [ ] **에러 로깅·모니터링**(Dewy `client_error_logs` 등가물 없음) — 프로덕션 관측 불가.
- [ ] **테스트·CI**(`.github` 없음), `next.config` 비어 있음, rate limit·캐싱.
- [ ] 이미지 업로드 **UI**(버킷만 있고 UI 없음), 영상 저장.
- [ ] **모바일 플랫폼 결정**(웹/PWA/앱) + **iOS·사파리 회귀 함정**(Dewy 교훈) 점검.

### G. 인증·계정·신뢰안전 [부분]
- [ ] 비밀번호 재설정, 이메일 인증 페이지(현재 빈 컴포넌트), **계정 삭제(§35)**.
- [ ] 리뷰·평점·분쟁처리·**도용 모니터링**(협회 검증으로 초기 완화, 확장 시 정책).

### H. 수요(소비자) 획득 [부분 맹점]
- [ ] 작가 모집은 협회로 해결되나 **소비자 유입은 별개** → 천안 로컬 PR·협회/재단 행사·관광·단체수요·ASO/SEO 등 수요측 GTM([`marketing-plan.md`](./marketing-plan.md) GTM 절).

## 구분 요약

- **[맹점](기획서에도 없음 — 가장 위험)**: ① 커머스/수익 모델 ② 법무 페이지·전자상거래법·통신판매중개 ③ 발행 전 사람 검수 ④ 관측/모니터링 ⑤ 영상 운영 파이프라인 ⑥ 소비자 획득 채널.
- **[미구현](기획엔 있으나 코드 0)**: 소비자 스키마·취향 프로파일·발견 피드·match_tags·임베딩·생성기·브랜드 보이스·정보통신망법 메시지·harness.
- **구현됨(✅)**: 작가 이메일/비번 인증, 3-step 온보딩, 기본 스키마+RLS+share_token RPC, 스토리지 버킷(업로드 UI 없음).

## 수익 모델 (미정 — 결정 필요)

작가 부담 0 + 리드젠이면 수익원 후보: ① 지자체·재단 지원·B2G([`proposal-cheonan.md`](./proposal-cheonan.md)) ② 추후 거래 수수료(마켓플레이스 전환) ③ 소비자 프리미엄.
**천안 파일럿 단계는 "검증 우선, 수익 후순위".** 마켓플레이스 전환 시점에 수수료 모델 확정.

## 권장 착수 순서 (천안 비치헤드 · 단계적 거래)

1. **출시 전 필수(법무·관측)**: 개인정보처리방침·이용약관·사업자/중개 고지, 동의 스키마, 에러 로깅, 발행 전 사람 검수.
2. **천안 파일럿 — 컨시어지 MVP**: 협회 작가 N명 인터뷰·큐레이션 → 소비자 발견 v1(취향 온보딩·피드·작가 소개 영상), 구매는 작가 채널 연결(리드젠).
3. **AI 생성기 백엔드 + harness**: 5종 생성 + 시각브리프=매칭태그 적재, 모델 라우팅 검증.
4. **지역 확장 + 마켓플레이스 전환(Phase B)**: 인접 인터뷰어 네트워크, 결제·정산·에스크로·청약철회·배송·분쟁 + 통신판매업.

## Verification

- 코드 실측(존재/부재)으로 검증함. 구현 시 **페르소나 walkthrough**(소비자 발견→작가 채널 이동, 작가 인터뷰→발행)로 막다른 단계 0 확인.
- 법무 항목은 **전문가 검토 필수** — 본 문서는 체크리스트이지 법률 자문이 아니다.
